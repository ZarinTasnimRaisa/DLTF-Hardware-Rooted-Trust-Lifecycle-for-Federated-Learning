Six scenarios, every number a live run

Five attacks and one honest negative control. Each trace is the v3 engine reacting round by round; the status strip shows what the system actually did. The honest control is where v3's one measured shortfall lives — it is reported in full, not smoothed over.

FLAGD1/reinstate: with W=2 the floor need_s=(r/(1-r))(b0+f)-a0 exceeds the max trial credit theta*W_MAX=0.4*9=3.6 for every f>=tau, so all reinstatements return at exactly 0.75; the v2.1 'stronger recovery returns higher' property is retired (REINSTATE_T is coupled to W).
FLAGD2/tau: at the shipped tau=0.6 the 200-round honest sanction rate is 28% (not ~0%). This is a STEADY-STATE cluster effect, not cold start: each MINOR adds tau AND resets the clean-run counter, blocking the 5-round fade. The u-gate removes the cold-start component only (see D2/gate).
FLAGD2/gate: gate ON cuts the 20-round cold-start FP to 2% (from 15%); the 200-round residual is unchanged at ~28%. The handoff's 8%/64%/64% baseline is the v2.1 informative-prior SYSTEM, not v3 gate-OFF (v3 gate-OFF 20-round ~15%).
FLAGD3/negative-control: 5/20 honest devices sanctioned over 200 rounds at tau=0.6 (target was ~0%). Tier-1 cases are recoverable probations; T2/T3 would be permanent bans. Root cause is steady-state MINOR clustering, not cold start.
Attack · persistent

Persistent attacker

Setup. Fresh Tier-1 device sends a poisoned update every round.
Defense. M3 run rule (ungated), then the score backstop

OUTCOME Probation at round 2 via the ungated M3 run rule (trust 0.3125) — the u-gate does not delay M3, banned at round 4 once the score fell below the 0.3 backstop from probation (D5). From probation its weight is capped at 0.1.
Attack · sleeper

Sleeper attack

Setup. 40 clean rounds to bank goodwill, then attacks every round.
Defense. M3 sustained-run escalation + M1 bounded memory

OUTCOME Caught at attack round 2 (global 42) with trust still 0.6558 — the score alone would not yet sanction, but the ungated run rule does. M1 caps banked goodwill at trust 0.8317 (ceiling 0.8333).
Attack · onoff

On-off attack (period 5)

Setup. 1 attack + 4 clean rounds, repeated — rests exactly the forgiveness window minus one.
Defense. M2 earned forgetting (FORGIVE_AFTER = 5)

OUTCOME Penalty f ratchets monotonically (0.6 -> 8.4): each attack resets the clean-run counter, so the 5-round fade never triggers and rest phases launder nothing. Contained at round 21. Slower than a persistent attacker, never escapable.
Attack · whitewash

Whitewashing (ban evasion)

Setup. A banned device tries to rejoin: (a) same hardware EK, (b) a fresh software identity.
Defense. O2 EK-bound ban + Friedman-Resnick newcomer pricing

OUTCOME Same hardware -> BANNED at registration (weight 0), enforced on-chain at register time. A fresh software identity restarts at weight 0.05 — 16x below the influence it burned.
Attack · sybil

Confirmed Sybil (CRITICAL)

Setup. 30 clean rounds of banked history, then confirmed identity abuse.
Defense. CRITICAL rule — non-compensable, ungated, no arithmetic

OUTCOME Instant ban. CRITICAL is a rule, not evidence, so 30 rounds of banked goodwill and the u-gate are both irrelevant to it.
Attack · honest

Negative control: honest but noisy

Setup. 20 honest Tier-1 devices, 5% spurious MINOR per round, 200 rounds.
Defense. (gate ON; the honest residual is reported, not hidden)

DEVIATION 5/20 devices left ACTIVE at some point over 200 rounds — a steady-state residual driven by tau=0.6 clustering, NOT cold start (gate-OFF cold-start flagged 1/20 in the first 20 rounds alone). On Tier 1 these are recoverable probations, not bans. Trust stays in [0.4595, 0.8328]. This is the ~0% target deviation, surfaced honestly: the gate fixes cold start; the residual is the price of Kang's cited tau.
